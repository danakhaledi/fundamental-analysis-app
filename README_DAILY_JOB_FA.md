# راه‌اندازی جاب خودکار روزانه بازار

1. ابتدا برنامه را یک بار با `run_windows.bat` اجرا کنید تا محیط `.venv` و تنظیمات اولیه آماده شود.
2. فایل `configure_daily_job.bat` را اجرا کنید و ساعت اجرای روزانه را با قالب ۲۴ ساعته وارد کنید؛ مثلاً `07:00`.
3. مقادیر درخواستی را تعیین کنید:
   - **Symbol resolution batch size**: تعداد نمادهای بررسی‌شده برای تبدیل شناسه موقت به شناسه رسمی در هر نوبت (پیش‌فرض 500).
   - **Maximum symbol resolution rounds**: سقف تعداد دسته‌های بررسی شناسه در هر اجرای روزانه (پیش‌فرض 20).
   - **Maximum full backfill passes**: سقف دفعات تلاش مجدد برای تکمیل تاریخچه نمادهای بدون سابقه (پیش‌فرض 3).
4. لاگ اجرا و خطاها در `logs\market_daily_sync.log` ذخیره می‌شود. فایل با هر اجرا ادامه پیدا می‌کند و زمان هر پیام را ثبت می‌کند.

## منطق اجرا

- ابتدا فهرست نمادها از TSETMC تازه‌سازی و در SQLite محلی ذخیره می‌شود.
- سپس شناسه‌های رسمی در دسته‌های محدود بررسی و نمادهای رسمی به SQL Server منتقل می‌شوند.
- تاریخچه نمادهای فاقد سابقه در دسته‌های حداکثر 100تایی دریافت می‌شود تا پایان فهرست؛ در صورت وجود خطا، چند گذر مجدد انجام می‌شود.
- پس از آن، یک چرخه کامل به‌روزرسانی تاریخچه قیمت نمادهای رسمی در دسته‌های حداکثر 100تایی اجرا می‌شود.
- نشانگر آخرین `InsCode` در SQLite نگهداری می‌شود تا اجرای بعدی بتواند از محل قبلی ادامه دهد.
- قفل اجرا مانع اجرای هم‌زمان دو جاب می‌شود.

## خطاها و محدودیت‌ها

- اگر سرویس TSETMC یا SQL Server خطا بدهد، جزئیات خطا در لاگ ثبت می‌شود. برای رفع خطا، لاگ را بررسی و جاب را دوباره اجرا کنید.
- برای جلوگیری از حلقه بی‌پایان در صورت خرابی دائمی سرویس یا نماد، تلاش‌های تاریخچه سقف دارند؛ اجرای دارای خطای حل‌نشده با کد خروج غیرصفر تمام می‌شود.
- شناسه‌های موقت که در جست‌وجوی TSETMC تطبیق یکتا ندارند، ممکن است همچنان باقی بمانند؛ در لاگ هشدار ثبت می‌شود و آن‌ها مانع دریافت تاریخچه نمادهای دارای شناسه رسمی نمی‌شوند.
- زمان‌بندی با Windows Task Scheduler انجام می‌شود؛ رایانه باید در زمان اجرا روشن باشد. برای اجرا هنگام خاموش بودن رایانه، گزینه اجرای پس از ازدست‌رفتن زمان‌بندی را در Task Scheduler فعال کنید.
- پیش از اتکا به زمان‌بندی، یک بار از Task Scheduler گزینه Run را اجرا و `logs\market_daily_sync.log` را بررسی کنید. این بسته در این محیط به TSETMC و SQL Server واقعی شما متصل و آزمایش نشده است.

## مدیریت از داخل رابط کاربری
از «مدیریت نمادها» وارد «تنظیمات و گزارش جاب خودکار» شوید. از همان صفحه می‌توانید زمان روزانه را ذخیره کنید، جاب را دستی اجرا کنید، زمان‌بندی را حذف کنید و جدیدترین خطوط لاگ و خطاها را ببینید. دکمه «رفرش وضعیت و لاگ» اطلاعات تازه را از Task Scheduler و فایل لاگ می‌خواند. دسترسی این صفحه مخصوص مدیر برنامه است.
